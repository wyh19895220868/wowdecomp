# 3.3.5 游戏内素材预览

客户端内置了 `MaterialPreview`，它把选定的 WoW UI 贴图作为普通客户端 TGA 资源加载，使用游戏自己的 Texture/UI 渲染路径显示。

1. 启动 `D:\wow_cn_3.3.5\WowClient64.exe` 并进入角色世界。
2. 输入 `/素材`（也支持 `/materialpreview` 或 `/matpreview`）。
3. 用“上一页/下一页”查看精选素材；悬停素材可以看到原 PNG 路径和尺寸。

当前仓库带有 36 个代表性素材。原始目录约 10 GB，不会一次性全部复制成 TGA。需要查看其他 PNG 时，在源码根目录执行：

```powershell
.\Tools\Convert-WowUiTexturesToTga.ps1 `
  -SourceRoot 'E:\wowdecomp\wow素材\wow-ui-textures' `
  -OutputRoot '.\Interface\NativeUI\BundledAddOns\MaterialPreview\Textures' `
  -RelativePath 'Buttons\UI-Panel-Button-Up.PNG' `
  -Force
```

转换后的文件名会把目录分隔符替换为 `__`。将新文件加入 `MaterialPreview.lua` 的 `ITEMS` 表后重新构建并部署客户端即可。
